Design system

Everything the portfolio is built from. Tokens live in assets/css/tokens.css, component styles in assets/css/components.css and component behaviour in assets/js/components.js. Change a token or a component once and every page updates. Each example below shows its real source — copy it into a page to use it.

Colour

Primitives are the raw palette from Figma. Components use the semantic tokens only — to re-theme the site, point a semantic token at a different primitive.

Motion

--ease-out with --duration-fast (0.2s, colours), --duration-base (0.35s, shadows) and --duration-slow (0.6s, movement). All motion is switched off for visitors who ask for reduced motion.

Buttons

.btn plus a variant: .btn--dark, .btn--orange or .btn--outline. Add .btn--small for the small size. The arrow icon is optional. .round-btn is the round arrow used by the slider.

Case card <case-card>

A product design case study: image, details line, tags, title and text. The element marked slot="title" becomes the title; everything else becomes the text. Pick the heading level that fits the page (h2 on a list page, h3 under a section heading).

AttributeDescription
image, altImage path and its description.
detailsCompany · Year · Industry · Place
tagsComma-separated tags (rendered with <pill-list>).
layoutOptional. reverse = image on the right. secondary = compact dark card.

Project card <project-card>

A visual design project. The description (the element's text) slides in on hover or keyboard focus, and is always visible on phones. Keep it to two lines.

AttributeDescription
nameProject name.
image, altImage path and its description.
tagsComma-separated tags.
headingOptional heading tag for the name: h2 (default), h3 or h4.
Short project description. Two lines only.

Logo marquee <logo-marquee>

An endless, auto-scrolling row of logos that pauses on hover. Put logos inside as <img>; wrap one in <a> to link it. Set each logo's desktop width with style="--w:160" (in px; mobile uses 60%).

Dot shader <dot-shader>

Recreates the Figma particle shader: a shape drawn as a grid of dots that push away from the cursor and change colour. Give it a size with CSS. Put an inline <svg> inside (like the RENÉE wordmark), or use shape="pill". Move your mouse over the examples.

AttributeDescription
spacingDistance between dots in px. Default 5.
colorDot colour at rest. Default #f6f6f6.
hotDot colour near the cursor. Default #ff7e0d.
radiusHow far the cursor reaches, in px. Default 228.
shapeOptional. pill draws a rounded bar instead of the inline SVG.

Life stack <life-stack>

Statements next to a stack of tilted photos. Hovering or clicking a statement brings its photo to the front. Add one <life-moment> per statement, with image and alt. The first one starts on top.
